**WARM UP QUESTIONS**    
What does DNS do, why can't we just use IP address directly? Domain name system, creates a readable name for IP address (since IP can change). 

What does 404 and 200 mean? It's the status code, 404 = files not found and 200 = okay. 

When you view a webpage, what file does your browser download? Html files. 

What's the difference between GET and POST? GET = load a page, POST = submitting a form.
