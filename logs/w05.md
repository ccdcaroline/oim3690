**3 ways to add CSS to a page?** External CSS files outisde that you link. Internal using < style > within < head>. Inline adding directly inside HTML. Normally use external. 

**What does "cascading" mean in CSS? If you have the same property in an external styleshee and an inline style, which wins?** Cascading refers to the hierarchy uses to determine which style rule applies when there is conflicting instructions. Inline wins because of higher specificity. 

**SELECTORS** 
- Elements: Targets all element types, p{ }
- Class: Targets elements with class, .intro{ }
- ID: Targets all elements with ID, # header{ }
- Universal: All elements, * {}

**Every Element is a Box** 
- Content: The actual content. 
- Padding: Space inside the border 
- Border: The edge 
- Margin: Space outside the border
