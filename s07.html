🎓 Basic HTML Tags & Elements Guide

1. Structural Tags

<html> Tag

Purpose: Root element that wraps all content

Example: <html lang="en">...</html>

This is the container for your entire HTML document.

<head> Tag

Purpose: Contains metadata, title, links, and scripts

Example: <head><title>My Page</title></head>

Information here is NOT displayed on the page (except title in browser tab).

<body> Tag

Purpose: Contains all visible page content

Example: <body><p>Hello</p></body>

Everything users see goes here!

2. Text & Heading Tags

<h1> through <h6> Tags

Purpose: Define headings (h1 = largest, h6 = smallest)

This is H1 - Main title

This is H2 - Subtitle

This is H3 - Section heading

Usage: Use h1 once per page for main title, then h2-h6 for sections.

<p> Tag

Purpose: Defines a paragraph

Example: This is a paragraph. The browser automatically adds space before and after.

Each <p> tag creates a block of text with automatic margins.

3. Text Formatting Tags

<strong> & <b> Tags

Purpose: Make text bold

<strong> - Semantic (indicates importance), displays bold

<b> - Just for styling, displays bold

Recommendation: Use <strong> for semantic meaning.

<em> & <i> Tags

Purpose: Make text italic

<em> - Semantic (emphasized), displays italic

<i> - Just for styling, displays italic

Recommendation: Use <em> for semantic meaning.

<mark> Tag

Purpose: Highlight text

This is highlighted text (usually yellow background).

<small> Tag

Purpose: Make text smaller (for fine print, disclaimers)

This is smaller text, often used for copyright or fine print.

<del> & <ins> Tags

Purpose: Show deleted and inserted text

The price was $100 $50.

<del> shows strike-through, <ins> shows underline.

4. List Tags

<ul> & <li> Tags (Unordered List)

Purpose: Create a bulleted list

  • First item (bullet point)
  • Second item
  • Third item

<ol> & <li> Tags (Ordered List)

Purpose: Create a numbered list

  1. First step
  2. Second step
  3. Third step

<dl>, <dt>, <dd> Tags (Description List)

Purpose: Pair terms with definitions

HTML
HyperText Markup Language - used to structure web content
CSS
Cascading Style Sheets - used to style web content

5. Links & Media Tags

<a> Tag (Anchor/Link)

Purpose: Create hyperlinks

<a href="https://example.com">Click me</a>

Click me (opens in new tab)

Attributes: href (URL), target="_blank" (opens in new tab)

<img> Tag (Image)

Purpose: Display images

<img src="image.jpg" alt="Description">

Attributes: src (image path), alt (description if image fails)

Note: <img> is a self-closing tag (no closing tag).

6. Container/Division Tags

<div> Tag

Purpose: Generic container for grouping - used to section content

Example: <div class="container">...</div>

The most commonly used container. Apply styling/layout with CSS.

<section> Tag

Purpose: Semantic container for a thematic grouping

Example: <section><h2>About Us</h2>...</section>

Better for SEO and accessibility than <div>.

<header> Tag

Purpose: Introductory content or navigation bar

Usually contains logo, navigation links, title.

<footer> Tag

Purpose: Footer content

Usually contains copyright, contact info, links.

<nav> Tag

Purpose: Navigation links

<nav><a href="/">Home</a></nav>

7. Form Tags

<form> Tag

Purpose: Create a form to collect user input

<form action="submit.php">...</form>

<input> Tag

Purpose: Create input fields

Text: <input type="text">

Password: <input type="password">

Checkbox: <input type="checkbox">

Radio: <input type="radio">

Submit: <input type="submit" value="Send">

<label> Tag

Purpose: Label for form inputs

<label for="name">Name</label><input id="name">

<textarea> Tag

Purpose: Multi-line text input

<textarea rows="4" cols="40"></textarea>

<button> Tag

Purpose: Clickable button

<button>Click Me</button>

8. Other Useful Tags

<hr> Tag (Horizontal Rule)

Purpose: Draw a line to separate content

Note: Self-closing tag.

<br> Tag (Line Break)

Purpose: Create a line break

Line 1
Line 2
Line 3

Note: Self-closing tag. Use sparingly; CSS is better for spacing.

<table>, <tr>, <td> Tags

Purpose: Create tables

Cell 1 Cell 2
Cell 3 Cell 4

<code> & <pre> Tags

Purpose: Display code snippets

Inline code: var x = 5;

Block of code:
var name = "John";
var age = 25;

✨ Quick Summary

Document Structure

  • <!DOCTYPE html> - Declares this is an HTML5 document
  • <html> - Root element
  • <head> - Metadata & info
  • <body> - Visible content

Best Practices

  • Use semantic tags (<header>, <section>, <footer>) for better organization
  • Always include <alt> text for images
  • Use <strong> instead of <b>, <em> instead of <i>
  • Close all tags properly
  • Use lowercase for tag names
  • Indent code for readability
